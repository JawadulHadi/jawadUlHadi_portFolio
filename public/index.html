Engineering Deep Dive · Problem Statement & Architecture Specs

⚠️ The Enterprise Reality of LLMs in Production

Third-party LLM APIs suffer from unpredictable rate-limits (HTTP 429), regional outages (HTTP 503), latency spikes (10s+ pauses), and strict token budget constraints. If an enterprise platform couples core operations directly to raw LLM calls, a single upstream outage brings hiring pipelines and recruiter consoles to a hard stop.

🛡️ The Architectural Solution

A single Unified AI Service backed by BullMQ/Redis idempotent queues and a strict 3-tier resilience ladder: Tier 1 (automatic multi-provider retry/failover) → Tier 2 (tenant-scoped RAG grounded vector retrieval) → Tier 3 (deterministic rule-based OCR & pattern floor). The system never returns a 500 error to users.

Core Architecture Specifications & Design Guarantees

  • Provider Agnosticism: Dynamic switching between Google Gemini, OpenAI GPT-4o, and Anthropic Claude 3.7 with no downstream caller code modification.
  • Multi-Tenant Isolation: Vaulted per-tenant API keys and metadata-filtered vector queries ensuring zero cross-tenant data leakage.
  • Idempotent Processing: BullMQ queue workers with deterministic job IDs prevent duplicate billing or token consumption during retries.
  • Zero Cold-Start Lag: Lightweight pre-computed vector indices allow instant snippet fallback when upstream LLMs experience transient spikes.
UnifiedAIService.ts — Production Provider Abstraction & 3-Tier Fallback Ladder TypeScript / NestJS 
export class UnifiedAIService {
  async executeWithReliabilityLadder<T>(
    req: AIRequestPayload,
    tenantContext: TenantSecurityContext
  ): Promise<AIResponse<T>> {
    // Tier 1: Multi-Provider LLM with Exponential Retry
    try {
      return await this.dispatchPrimaryLLM(req, tenantContext);
    } catch (llmErr) {
      this.logger.warn(`Tier-1 LLM failed: ${llmErr.message}. Escalating to Tier-2 RAG.`);
    }

    // Tier 2: Tenant-Scoped Grounded Vector Retrieval (RAG Fallback)
    try {
      const vectorMatches = await this.vectorStore.searchByTenant({
        tenantId: tenantContext.tenantId,
        query: req.queryText,
        threshold: 0.78
      });
      if (vectorMatches.length > 0) {
        return this.formatGroundedSnippets(vectorMatches, 'TIER_2_RAG');
      }
    } catch (ragErr) {
      this.logger.warn(`Tier-2 RAG empty/failed: ${ragErr.message}. Escalating to Tier-3 Floor.`);
    }

    // Tier 3: Deterministic Rule-Based Heuristics & OCR Floor
    return this.ruleEngine.extractHeuristicData(req.rawDocument, 'TIER_3_RULE_FLOOR');
  }
}
